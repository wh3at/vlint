# ルール計測区間の開始時と終了時だけ検証する

#37では、ready状態に影響しない属性変更でもCSS依存の保守的な履歴判定によってincompleteになるため、URL・フォント・ready条件の確認を各ルールの評価開始時と終了時に統一する。ADR-0001の計測中監視を置き換え、途中のURL往復、同一URLの再読込、hide/show、要素の置換、フォント再読込は終了時に条件を満たせば許容し、区間全体の状態維持よりも予測可能な判定と単純な実装を優先する。初期取得時のredirect照合と読込・フォント・ready待機、固定URLの厳格な照合、終了時に条件を満たさないルールの検査失敗は維持する。

各境界の確認もブラウザー操作によるサンプリングであり、ready条件の一致集合とURL・フォントの確認をまたぐ原子的なスナップショットは保証しない。確認間や確認後の変化まで排除するための監視・ページ停止・独自selector実装は導入しない。
