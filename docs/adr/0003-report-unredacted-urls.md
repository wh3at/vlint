# terminalで設定URLと実測URLを生値で示す

対象ページの設定URLと実測URLは成功・失敗を問わず対象ページとデバイスごとにterminalとJSONの両方へ生値で出力し、terminal側のquery値・hashの伏せ字を廃止する。ブラウザーで実測できなかった場合は実測URLを空として扱い、途中の遷移が検出されて失敗した場合はその失敗にも検出URLを示す。実測URLが異なる理由をそのまま確認でき、形式間の挙動も揃う一方、URLに秘密情報を含めた場合はterminalログに残る。URLに秘密情報を含めない運用を選び、ログを扱う側がその責任を負う。制御文字の安全な表示処理は維持する。

[#55](https://github.com/wh3at/vlint/issues/55)で、全成功ケースのURLを通常出力へ列挙する方針だけを置き換えた。terminalとJSONの通常出力は検査範囲サマリーと違反・失敗の対処情報へ絞り、成功ケースの詳細は`reportPath`が示す同じ実行の完全レポートから取得する。表示する診断と完全レポートでは指定URL・実測URLのquery・hashを含む生値を維持し、terminalの制御文字の安全処理と厳格なURL照合も変更しない。保存とCIでの保持方法は[完全レポート](../operations/reports.md)を参照。
