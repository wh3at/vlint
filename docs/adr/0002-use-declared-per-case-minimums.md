# 宣言された組み合わせだけ最低検査件数を保証する

最低検査件数は対象ページ・デバイス・ルールの組み合わせに対して任意で宣言し、宣言された下限だけを検査の成功条件とする。ルール共通の値を対象ページ・デバイス・その組み合わせで上書きできるようにし、対象ページとデバイスの上書きが異なる場合は組み合わせの値を明示しない限り設定エラーにする。従来の`minimumLabels`・`minimumHeaders`は後方互換のために残さず、`allowZeroLabels`・`allowZeroHeaders`と実行全体の0件判定も廃止する。全体0件判定は下限の設定忘れを一部防いでいたが、特定の対象ページ・デバイスの検査漏れは検出できず、共通下限と競合するためである。移行時には要素の存在を期待する組み合わせに下限を明示する必要があり、未宣言なら0件でも成功し得ることを文書化する。
